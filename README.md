**Pong Clone**

A 2D Pong clone, recreating the 1972 Atari game. Built as a hands-on project to learn Unity's physics system, the input system, and script architecture. 

**Gameplay**

Left paddle: w/s

Right paddle: up/down arrows

Press space to start

**Highlights**

Custom ball bounce based on where it collides with the player paddle

GameManager script handles game state, score, and win conditions

Reusable scripts that can be changed in the inspector

**Running it**

Open in Unity, load the Pong Clone scene, press Play
